# HSJ Research

A small collection of free research material related to HSJ analysis, fingerprint values, VM data reversing, and encryption behavior.

## Repository Contents

| File                  | Description                                                                       |
| --------------------- | --------------------------------------------------------------------------------- |
| `fingerprint_docs.md` | Explanation of fingerprint values and their meaning                               |
| `REVERSE_VMDATA.md`   | Notes and documentation about reversed VM data                                    |
| `crypto.py`           | Research implementation of the encryption algorithm and currently documented keys |
